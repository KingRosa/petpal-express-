# 🐾 PetPal Express

PetPal Express is a full-stack pet adoption web application built with React, Express, Node.js, Firebase Admin, and Cloud Firestore.

## Features

- Discover randomly generated pets
- Dog, cat, and rabbit listings
- Filter pets by animal type
- Adopt pets
- Return adopted pets
- Persistent adoption status using Firestore
- Dynamic pet images
- Responsive React interface
- REST API backend

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express
- Firebase Admin SDK
- Cloud Firestore
